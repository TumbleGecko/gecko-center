# Gecko Center

Gecko Center is the one place to look after [openSUSE Tumbleweed](https://www.opensuse.org/#Tumbleweed), its updates, apps, health, snapshots and drivers.\
It sits at the heart of [TumbleGecko](https://github.com/TumbleGecko/tumblegecko), which installs it, shows everything it does and is where it is mostly tested.

## Install

```sh
git clone https://github.com/TumbleGecko/gecko-center.git
cd gecko-center
./gecko-center.sh
```
